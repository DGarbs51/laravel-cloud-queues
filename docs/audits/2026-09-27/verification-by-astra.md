## Most consequential corrections

1. **GET retries are misstated twice.** `[0, 500]` means **three total attempts**, with retries after 0 ms and 500 ms, not one retry after 500 ms (`C:27`, `R:43`).
2. **Queue identity is conflated.** Laravel lifecycle normalization uses the requested pop queue, not the agent message's `queueUrl`; the agent report contains no queue URL (`C:32`).
3. **“Non-object” is the wrong JSON rule.** Both clients use a PHP-array check, accepting decoded JSON objects **and arrays**; `[]` is an empty poll (`R:44`).
4. **Timeout reporting is conditional and ordered differently.** Failure checks precede stopping telemetry; exhausted attempts, expired retry deadlines, exception limits, and fail-on-timeout can make the event `failed`. Successful exit-124 mechanics and later redelivery are not unconditional guarantees (`C:28`, `R:45`).
5. **The socket fixture is not the retry integration harness.** `AgentSocketIntegrationTest` runs it; `CloudRetryIntegrationTest` uses mocked SQS operations (`C:39`).
6. **Several “consensus” bullets are new policy.** Ignoring active config keys, mandatory deferral of advanced retry features, blanket refusal of local endpoints, and unconditional prohibition of the failed-job fetch workflow were not all agreed by the tagged auditors.
7. **The README loses material safety findings.** Best-effort failure-record loss, full-envelope destruction by Symfony's projection, credential refresh, cancellation/ack races, independent evidence tiers, and several downstream typing/packaging checks need explicit representation.
